## 📌 Sobre o projeto

Esse projeto propõe o desafio de entender por meio de análise de dados o problema de cancelamentos dos serviços de uma empresa. Temos uma base de dados e vamos usar alguns filtros para obter uma resposta mais precisa do motivo e alinhar com os responsáveis da empresa qual a melhor estratégica a ser aplicada para mudar esse cenário. Achei muito interessante a possibilidade de integrar com Power BI, mas essa parte não será abordada aqui.

> 💡 **Ideia central:** Análisar dados para resolver problemas de cancelamento de serviços.

---

### 🎯 Objetivos

- 🕒 Estabelecer o perfil dos clientes que cancelam.
- ⚙️ Filtrar informações relevantes
- 🧩 Encontrar pontos/ processos problemáticos
- 📚 Fornecer uma estimativa em percentual pós correção dos problemas
- 🚀 Alinhar as melhores abordagens

## 🚀 Instalação

### Pré-requisitos

- [Python 3.10 ou superior](https://www.python.org/downloads/)
- Git instalado na máquina
- Jupyter instalado como extensão do Visual Studio Code

### 1. Clone o repositório

```bash
git clone https://github.com/jonatttan/python_projects_for_begginers.git
cd Data_analysis_with_Python
```

### 2. Instale as dependências

```bash
pip install -r requirements.txt
```
