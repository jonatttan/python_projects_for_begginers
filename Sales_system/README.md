## 📌 Sobre o projeto

Esse é um sistema de vendas desenvolvido na linguagem Python com bibliotecas como o Streamlit pra renderizar na web, Pandas para manipular base de dados e Plotly para construção de gráficos. A prática da construção desse sistema trás uma boa noção do desenvolvimento de similares e mostra que novos horizontes podem ser desbravados como outras operações na base de dados e possibilidade de gráficos, além da exploração na montagem de layout web de forma facilitada (pelo menos pra quem já montou um site em HTML puro 🤭).

> 💡 **Ideia central:** Construção de um sistema de vendas usando Python.

---

### 🎯 Objetivos

- 🕒 Construir um sistema de vendas usando uma ferramenta de solução pra web (Lib streamlit).
- 🎲 Lidar com base de dados usando a lib Pandas.
- 📊 Criar gráficos com a lib Plotly.
- 📚 Consolidar conhecimentos.
- 🚀 Conhecer as possibilidades de evolução do projeto.

## 🚀 Instalação

### Pré-requisitos

- [Python 3.10 ou superior](https://www.python.org/downloads/)
- Git instalado na máquina

### 1. Clone o repositório

```bash
git clone https://github.com/jonatttan/python_projects_for_begginers.git
cd Sales_system
```

### 2. Instale as dependências

```bash
pip install -r requirements.txt
```

---

## ▶️ Como usar

Depois de configurar o ambiente, ainda no diretório do arquivo 'SalesSystem.py", execute o comando abaixo no terminal.
```bash
streamlit run SalesSystem.py
```
